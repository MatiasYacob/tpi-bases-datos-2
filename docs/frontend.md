# Frontend

React, TypeScript y Vite. Consume la API Express para administrar clientes, productos y pedidos y consultar el reporte de ventas. La interfaz espera confirmación del servidor para las escrituras y utiliza baja lógica.

Configuración y ejecución: ../frontend/README.md. Recorrido: ../frontend/USO.md. Revisión funcional: revision-cruzada.md. Comprobación de compilación: npm run build desde frontend.
